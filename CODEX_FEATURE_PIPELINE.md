# Codex Feature Pipeline

Núcleo independente para Postify e outros repositórios. Esta versão entrega classificação, CLI, dry-run, instalador Windows e comandos globais; a execução de fases Codex, hook e validações do projeto será conectada na etapa seguinte.

Modelos previstos: Sol para planejamento/revisão e Luna para implementação. O pipeline não faz commits, push, deploy, reset do Git ou leitura de segredos.
